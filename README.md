### 🌐 Cara Mengaktifkan GitHub Pages (Agar Web Bisa Diakses Online)
1. Buka repositori ini di GitHub: `https://github.com/Fatogi/e-portofolio_seminar2`
2. Klik tab **Settings** (Pengaturan).
3. Di bilah sisi kiri, pilih menu **Pages**.
4. Di bagian **Build and deployment** > **Branch**:
   - Pilih branch `main`
   - Pilih folder `/ (root)`
   - Klik **Save**.
5. Tunggu 1–2 menit, web portofolio Anda akan aktif dan bisa diakses publik melalui tautan:
   👉 **`https://fatogi.github.io/e-portofolio_seminar2/`**
